# AniCape - Animated Minecraft Cape Creator

AniCape is a full-featured single-page web app designed to generate animated Minecraft cape and elytra textures compatible with mods like **Better Capes**.

## 🌟 Key Features
- **GIF Animation Support**: Decode any GIF into frame sequences rendered directly onto the cape.
- **3D Interactive Steve Preview**: Full Steve model with rotation, zooming, and Overworld background scenery.
- **Elytra Mode Toggle**: Real-time switching between 3D Cape and 3D Elytra geometry.
- **Better Capes Strip Export**: Download vertical frame sequence PNG textures ready for in-game use.

## 🛠️ Usage
1. Open VS Code and serve `cape.html` using **Live Server**.
2. Select any GIF file in the **GIF / Image Texture** box.
3. Adjust frame delay, quality resolution, or toggle Elytra mode as needed.
4. Download the generated texture sequence file.
